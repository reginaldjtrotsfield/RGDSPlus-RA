# RGDSPlus-RA v0.1.0

First public preview of RetroAchievements support for the stock RG DS Plus NNDDSS/DraStic-based Nintendo DS emulator.

This client is **not yet approved for RetroAchievements Hardcore**.

v0.1.0 intentionally uses spectator mode, so achievement and leaderboard submissions are disabled while the integration is undergoing public testing and review.

No NNDDSS, DraStic, firmware, BIOS, or ROM files are included.
